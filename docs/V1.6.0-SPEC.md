## PermissionGate API (NEW, all subagents use this — DO NOT inline `hasPermission` checks)

File: `common/src/main/java/network/vonix/serverutilities/features/PermissionGate.java`

```java
public final class PermissionGate {
    private PermissionGate() {}

    /** True iff source has node (LP path) or meets fallback op-level (vanilla path).
     *  Console always passes. */
    public static boolean check(CommandSourceStack source, String node, int opFallback) {
        if (!source.isPlayer()) return true; // console / command blocks / functions
        if (LuckPermsBridge.isPresent()) {
            return LuckPermsBridge.hasPermission(source.getPlayer().getUUID(), node);
        }
        return source.hasPermission(opFallback);
    }

    /** Predicate suitable for Brigadier .requires(). */
    public static Predicate<CommandSourceStack> requires(String node, int opFallback) {
        return s -> check(s, node, opFallback);
    }

    /** Composed: feature gate AND permission gate. THIS is the primary helper
     *  every command should use. */
    public static Predicate<CommandSourceStack> requires(String featureKey, String node, int opFallback) {
        return FeatureGate.requires(featureKey, requires(node, opFallback));
    }
}
```

`LuckPermsBridge` needs a new method `hasPermission(UUID, String) -> boolean` — synchronous, cached, returns true on LP-unavailable to fail-open ONLY if explicitly chosen by the caller (callers default to fail-closed because they only call this branch when `isPresent()`).

## Moderation subsystem (NEW)

Package: `common/src/main/java/network/vonix/serverutilities/moderation/`

### Schema (SQLite — co-located with existing VSU DB)

```sql
CREATE TABLE IF NOT EXISTS punishments (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    type          TEXT NOT NULL,         -- 'BAN' | 'MUTE' | 'KICK' | 'WARN'
    target_uuid   TEXT NOT NULL,         -- player UUID
    target_name   TEXT NOT NULL,         -- last-known name (for /banlist when offline)
    issuer_uuid   TEXT,                  -- null = console
    issuer_name   TEXT NOT NULL,         -- 'CONSOLE' or player name
    reason        TEXT,
    issued_at     INTEGER NOT NULL,      -- epoch millis
    expires_at    INTEGER,               -- epoch millis; NULL = permanent (BAN/MUTE) or N/A (KICK/WARN)
    active        INTEGER NOT NULL DEFAULT 1,  -- 0 = revoked or expired
    revoked_by    TEXT,                  -- name of unban/unmute issuer
    revoked_at    INTEGER
);

CREATE INDEX IF NOT EXISTS idx_punishments_target_active ON punishments(target_uuid, active, type);
CREATE INDEX IF NOT EXISTS idx_punishments_expires ON punishments(active, expires_at);
```

### Duration parser (must be exact)

Accept: `30s`, `5m`, `2h`, `7d`, `4w`, `1mo`, `1y`, `perm`/`permanent`/`never`.
Compose: `1d12h`, `7d6h30m`. No spaces.
Reject: any token without unit; negative; > 100 years.

Return `Optional<Long>` of milliseconds-to-expire, or empty for permanent.

### Enforcement hooks

- **Ban**: `PlayerLoginEvent` (NeoForge) / `ServerPlayConnectionEvents.JOIN` (Fabric) — check active BAN, disconnect with reason text formatted as `Banned: <reason>\nExpires: <iso> (<relative>)` or `Banned: <reason>\nPermanent`.
- **Mute**: `ServerChatEvent` (NeoForge) / `ServerMessageEvents.CHAT_MESSAGE` (Fabric) — cancel + send player a `§c[VSU] You are muted` message including expiry.
- **Mute** also catches `/me`, `/msg`, `/r`, `/tell`, `/broadcast` — when player is muted, these commands `.requires(s -> !MuteState.isMuted(s.getPlayer()))` (predicate AND'd with existing requirements).
- **Expiry sweeper** — `ScheduledExecutorService` every 60s, marks expired rows `active=0`, broadcasts to ops only on actual state change.

### In-flight player notifications

When tempban is issued against an online player, do not just `disconnect()` — use `tellraw` first with the brand, then 1s later disconnect, so they read the reason on screen before the kick lands.

Every Brigadier argument must be a `SuggestionProvider` that lists actual values, not the default "type something" hint:
